WHY IT MATTERS

A museum you can actually use.

Not a mock-up. Not screenshots. The whole OS — boot, lock, springboard, multitasking dock, apps — reimplemented in the browser with the same fanatical attention to detail as the original SwiftUI build.

01

Slide to Unlock

The shimmer, the knob, the bounce-back. Even the lock screen camera grabber works — drag it upward to snap straight into the viewfinder.

02

The Real Springboard

Icon pagination, a Working Utilities folder, page dots, Spotlight search (swipe right), and long-press jiggle mode for your downloaded apps.

03

Live Data, Live Radio

Real weather from open-meteo, quotes via stooq, maps you can pan, and a Web Audio synthesizer performing chiptunes inside iPod.

04

iOS 4 Multitasking

Double-click the Home button and the felt multitasking tray slides up — switch between recent apps and pause the music from anywhere.

05

Hardware-Grade APIs

Voice Memos records into IndexedDB, Camera snaps to the Camera Roll, Compass reads deviceorientation, DTMF tones ring from a real keypad matrix.

06

Stateful & Persistent

Settings stick. Notes persist. Badges clear. Wallpapers stay picked. Airplane mode really drops the bars. Reset it all from Settings → General.

QUESTIONS

Before you slide.

Does it actually work, or is it a screenshot?

Genuinely works. The lock screen drag physics, the springboard paging, the Utilities folder, the DTMF-capable keypad, a real calculator, a real stopwatch, notes that persist, Photos that include your Camera shots, weather pulled live from open-meteo, stock quotes from stooq — it’s all running as you read this. Safari really navigates the web (in an iframe), and Voice Memos really records to IndexedDB.

What survives a refresh?

Everything local: your wallpaper, brightness, airplane mode, Wi-Fi pick, passcode (if you set one), notes, mail you sent, read state, photos you took, voice memos, alarms, contacts you edited, App Store installs, and springboard jiggle-state. Server-side: nothing. There is no server. There is no backend. There is only the 2010 dream.

Why does Safari sometimes refuse to load a page?

Some sites send X-Frame-Options headers forbidding iframes. When that happens, tap “Open in New Tab” — the address bar still works, and Wikipedia, Hacker News, Example.com and Apache.org embed beautifully. This is a web platform limitation, not an OldOS limitation.

Is this affiliated with Apple or zzanehip?

No to both — this is an affectionate, attribution-respecting fan recreation hosted by TheEuHub on GitHub Pages. All credit for the concept, art direction, and original build goes to Zane and the OldOS contributors. All blame for the CSS goes to this site.

Can I run this offline?

Save the page, or clone the repo — it’s a static site. iPod music is synthesized live via Web Audio (no files needed), maps and Wikipedia need network, and everything else works with the Wi-Fi switched off — the bars will even tell you.
