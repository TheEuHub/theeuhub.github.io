SwiftUI, rendered by HTML.

Apple never shipped SwiftUI for the browser — so The OldOS Project grew its own. SWTK is a recursive-descent transpiler feeding a hand-written declarative runtime: real Swift syntax in, live HTML out. No build step. No WebAssembly. No framework — just a textarea and a Run button.

What this is

      
    
        
  • Real Swift, not a parody. The compiler reads @State, var body: some View, ForEach, modifiers and interpolation — then emits plain JS.
    • 
        
  • State is real. count += 1 invalidates the view and re-renders, the SwiftUI way — only here it never leaves the page.
    • 
        
  • Honest scope. It’s a subset: no @ObservedObject, no navigation stack, no animations yet. Unsupported syntax fails loudly with a line number, never silently.
    • 
      

    

  






  

    

      
01 — LEX

      
Swift, tokenized

      
A hand-written lexer splits your source — strings with \(interpolation), nested comments, operators like ... and ..< — into a flat token stream with line numbers.

    

    

      
02 — PARSE

      
Recursive descent

      
A small parser builds the view tree: VStacks, modifiers, if / else inside builders, ForEach with ranges or collections, ternaries, statements and all.

    

    

      
03 — RENDER

      
Descriptors → HTML

      
Modifiers become an immutable descriptor tree. The 600-line runtime diffs nothing — it rebuilds and re-mounts, restoring field focus and caret so it feels native.
