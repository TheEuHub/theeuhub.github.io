# TheEuHub/theeuhub.github.io (proton Browser Desktop)

`TheEuHub/theeuhub.github.io` hosts **proton** (deployed at `https://theeuhub.github.io/`), a pure static browser desktop environment built in plain HTML, CSS, and JavaScript with a monochrome black-and-white theme (`#000000` backgrounds, white text, and grey accents).

## Entry Gate and Cover Site

- **Math Helper cover page (`index.html`, `assets/math-helper.js`):** Visitors first land on a working IXL-style maths practice website with grade browsing, adaptive exercises, diagnostic flow, analytics, awards, membership, and local waitlist views.
- **Desktop sign-in:** Typing the site password (stored in `data/password.txt`) into the header search input and clicking **Sign in** enters the proton desktop; returning local accounts (`proton2.*` storage keys) can also click **Sign in** directly.
- **Account and desktop persistence (`assets/core.js`):** Each account saves custom settings, wallpapers, app customizations, and `/home/<user>` files locally in browser storage without a backend server.

## Desktop Shell, Window Manager, and Virtual Filesystem

- **Windowing (`assets/core.js`, `assets/styles.css`):** Draggable, resizable windows, Mint-style bottom panel, Start menu grouped by category (`System`, `Productivity`, `Media`, `Tools`, `Games`), desktop icons, and toast notifications. Raster app icons render cover-cropped without background tiles (`svg-icon=false`), while named SVG icons (`svg-icon=true`) keep their monochrome tiles.
- **AI Copilot panel (`Alt+C` / `#copilot-frame`):** Clicking the sparkle AI button beside the taskbar clock or pressing `Alt+C` docks **Mox** along the right edge of the desktop so windows automatically resize beside it.
- **Virtual File System (`assets/fs.js`):** Combines the read-only repository tree generated in `data/fs-manifest.js` with a writable `/home/<user>` directory. Files in the Files app open on single click, and `FS.appFor()` routes extensions to the matching app (`.txt`/`.md`/code -> Text Editor, `.pdf` -> PDF Viewer, images -> Image Viewer, audio/video -> VLC, `.swf` -> Ruffle Flash Player, console ROMs -> Web Retro).
- **Built-in Repository Search (`assets/search.js`):** The Browser app's address bar queries `data/search-index.js` (generated by `tools/gen-search-index.py`) alongside `data/fs-manifest.js` and the app/website catalogs so every repo document, app, and path is searchable offline.

## Mox Integration in `apps/productivity/mox/`

`apps/productivity/mox/app.html` embeds `apps/productivity/mox/website/index.html?nosw` (skipping a nested service worker so root `coi-serviceworker.js` stays unambiguous). Mox runs `SmolLM2 135M Instruct` (`smollm2-135m-instruct-q4_1.gguf`, 98 MB) locally using `@wllama/wllama` (`vendor/wllama/wllama.js` and `wllama.wasm`) and locally vendored `@wllama/wllama-compat` (`vendor/wllama/compat/`) with automatic Firefox/Safari compatibility mode, Table64 detection, CPU (`n_gpu_layers: 0`), single-thread (`n_threads: 1`), and compact-context fallbacks so the model initializes reliably without contacting external CDNs.

## Running, Regenerating Manifests, and Testing

- **Serve locally:** `python3 -m http.server 8000` from the repository root (HTTP is required because browsers block ES modules and WebAssembly over `file://`).
- **Deploy:** `.github/workflows/pages.yml` deploys the static root directly to GitHub Pages on pushes to `main`.
- **Regenerate indexes (strict order):** Run `python3 tools/gen-search-index.py` *first*, then run `python3 tools/gen-fs-manifest.py`, because `data/fs-manifest.js` records the byte size of `data/search-index.js`.
- **Test suite:** `npm test` runs `tests/system-desktop.test.cjs` and `tests/mox-ui.test.cjs` using `node --test` and JSDOM to verify all catalogs, VFS integrity, Mox UI/model handoffs, and desktop interactions.
